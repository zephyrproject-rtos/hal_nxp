--- Known Issues/Limitations:
    - No binary release of the library included
    - On A20/L20, the PRNG is implemented using the SFRMASK SGI register. If the SGI is busy when a PRNG request is issued, 
      the request remains indefinitely in a waiting state. This behavior is the root cause of the failures observed 
      in the non-blocking negative test cases.
    - On A2TS, par_nxpClCipher_multipart_nonblocking_sgi_flush_check -> known limitation, the key is not flushed from the SGI after nxpClCipher_finish() for the mode nxpClCipher_Mode_AES_CTR, possible test issue
    - On W70, par_nxpClCipher_multipart_nonblocking_sgi_flush_check -> known limitation, the key is not flushed from the SGI after nxpClCipher_finish() for the mode nxpClCipher_Mode_AES_CTR, possible test issue
              - sim_rsa_GenerateProbablePrime, par_nxpClSignature_RSA* tests -> fail with NXPCLSESSION_STATUS_ERROR. The failures are seen only in tests using 4096 key bit size
